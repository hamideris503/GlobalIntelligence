## 5. واقعیت rollback (صادقانه)

- هر دو فایل **untracked** بودند و هرگز در Git ثبت نشدند؛ بنابراین `git checkout`/`git revert` مسیری برای بازگرداندن آن‌ها **ندارد**.
- مسیر بازگشت اکنون مستند و تأییدشده است: `backups/legacy_ui_20261112/backend/static/` با هش یکسان و غیرقابل‌ثبت در Git (بخش ۲).
- نسخهٔ temp مالک هم دست‌نخورده باقی است؛ برای ریسک صفر باید همان پوشهٔ `backups/` در بکاپ دیسک/VPS هم وجود داشته باشد (خارج از حیطهٔ این repository).
- از نظر کارکردی این ریسک پذیرفته شده است: محتوای هر دو فایل در `index.html` ادغام شده و رابط جاری از آن‌ها استفاده نمی‌کند.
- اگر مالک بخواهد ریسک صفر شود: پشتیبان را به `backups/` (که در `.gitignore` است) منتقل کند و هش‌های بخش ۲ را دوباره تأیید کند.
