### Why a loopback forwarder

`tests/test_ai_chat.py` installs a socket guard that rejects every DNS lookup except loopback.
Pointing `DATABASE_URL` at the Docker service name `gi_postgres` therefore fails inside the suite.
A small stdlib TCP forwarder (`127.0.0.1:15432 → gi_postgres:5432`) runs **inside the test
container** so the suite still exercises real PostgreSQL over the network while satisfying the
loopback-only guard. The forwarder is test harness only; no application code was changed.
